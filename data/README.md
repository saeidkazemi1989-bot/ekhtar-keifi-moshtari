# پوشهٔ داده‌های شما

همهٔ چیزهایی که خودتان وارد می‌کنید اینجا نگه داشته می‌شود تا با ساخت دوبارهٔ گزارش
یا به‌روزرسانی برنامه از بین نرود. این پوشه در git ثبت نمی‌شود.

| فایل | محتوا |
| --- | --- |
| `8d-forms.json` | فرم‌های 8D که در داشبورد ذخیره کرده‌اید |
| `اصلاح ایرادها.xlsx` | اصلاح دستی متن «ایراد مشتری» و دسته‌بندی |
| `اصلاحات گروه‌بندی.xlsx` | اصلاح دستی گروه/خانواده/محصول/برنچ |
| `backups/` | نسخهٔ پشتیبان خودکار (۴۰ نسخهٔ آخر) |

## قواعد مهم

- **ویرایش‌ها را روی همین فایل‌ها انجام دهید**، نه روی نسخه‌های ریشهٔ پروژه؛ چون از اولین
  اجرا، نسخهٔ `data/` مبنا است و مسیر دقیق هم در `output/build.log` نوشته می‌شود.
- پیش از هر ذخیرهٔ فرم و هر ساخت گزارش، یک نسخهٔ پشتیبان زمان‌دار در `backups/` ساخته می‌شود.
- برای انتقال به نسخهٔ تازهٔ برنامه کافی است همین پوشه را کنار برنامهٔ جدید کپی کنید؛
  هیچ داده‌ای از دست نمی‌رود.
- اگر می‌خواهید از داده‌ها نسخهٔ دستی بگیرید، کل این پوشه را کپی کنید.
